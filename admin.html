Bundle Management

Bundles are stored in PostgreSQL. Add/edit endpoints are protected by the ADMIN role.

For production, connect this panel to a licensed data-vending provider so a verified payment can automatically deliver the selected bundle.

Payment Configuration

Security: Paystack secret keys stay on the server in environment variables. The webhook validates Paystack's HMAC signature before accepting a payment event.

The live Mobile Money flow supports Ghana providers through Paystack: MTN, ATMoney/Airtel Money and Telecel. Configure your live keys in .env.
